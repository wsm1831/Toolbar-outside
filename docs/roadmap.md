# 진행 계획

## 결정 사항
- Windows 11, 인터넷망(외부망) PC에서 사용. 업무망 전용 사이트(그룹웨어·사내 메일)와 서식 문서는 넣지 않음.
- 모양: 화면 아래 가운데 둥근 독. 모든 버튼은 같은 크기의 둥근 정사각형 아이콘.
- 다른 창과의 관계: 항상 위. 평소 반투명, 마우스를 올리면 또렷하게.
- 우선 혼자 써 보고, 괜찮으면 배포.
- Electron으로 먼저 만들고, 필요하면 C# WPF로 옮긴다.

## 단계
- [x] 1. 디자인 시안 — 독, 튀어오르는 메뉴 애니메이션
- [x] 2. 기본 앱 — 화면 아래 고정, 카테고리/아이콘, 사이트·프로그램·폴더 열기, JSON 설정
- [x] 3. 설정 화면 — 항목 추가·삭제·끌어서 순서 바꾸기, 아이콘 이미지, 투명도, 자동 실행
- [x] 4. 유틸리티 — 빠른 메모, 날짜 계산, 타이머·알람, 텍스트 정리, 클립보드 기록
- [x] 녹색 불빛(화면 보호기 차단) + 소등 시간
- [ ] 5. 실제 PC에서 써 보고 다듬기 (사이트 목록, 아이콘, 위치·크기)
- [ ] 6. 배포 준비 — 공용 메뉴 파일 나눠 주기, 사용 설명서

## 나중에 검토할 아이디어
- 설정 내보내기/불러오기(백업, 다른 사람에게 메뉴 나눠 주기)
- 단축키로 툴바 열기 (예: Ctrl+Alt+Space)

- 여러 모니터에서 표시할 모니터 고르기
- 업무 시간 끝날 때 알림

## C# WPF로 옮길 때
- `config.json` 형식을 그대로 쓴다 ([config-format.md](config-format.md)).
- 대응 기능: 투명 창 `AllowsTransparency`, 클릭 통과는 `WS_EX_TRANSPARENT` 를 상황에 따라 켜고 끄기,
  화면 보호기 차단 `SetThreadExecutionState(ES_CONTINUOUS | ES_DISPLAY_REQUIRED)`,
  튀어오르는 애니메이션 `Storyboard` + `ElasticEase/BackEase`, 트레이 `NotifyIcon`.
- 장점: 실행 파일이 작고(수 MB) 메모리를 덜 씀. 단점: 화면 수정이 HTML보다 번거로움.
