    메뉴 항목

    '위치'에서 다른 카테고리를 고르면 항목이 그쪽으로 옮겨집니다(예: 유틸리티 ↔ 툴바 바로가기). 왼쪽 손잡이를 잡고 끌면 순서가 바뀝니다. 아이콘을 누르면 직접 고른 이미지로 바꿀 수 있습니다. 홈페이지는 사이트 아이콘을, 프로그램은 실행 파일 아이콘을 자동으로 씁니다.

      모양

      마우스를 툴바에 올리면 또렷해지고, 떼면 이 투명도로 돌아갑니다.

      날씨

      30분마다 새로 가져옵니다. 날씨를 누르면 네이버 날씨가 열립니다.

      키워드 뉴스 알림

      한 줄에 키워드 하나씩 적으세요. 띄어 쓰면 두 낱말이 모두 들어간 기사를 찾습니다.

      API 인증키

      인증키는 이 PC의 설정 파일에만 저장됩니다. 다른 사람에게 설정 파일을 줄 때는 지우고 주세요.

      화면 보호기 차단 (녹색 불빛)

      소등 시간 ~

      소등 시간 동안 화면 보호기 차단 기능이 꺼집니다. 소등 시간 중에 불빛을 직접 누르면 그 시간 동안은 켜진 채로 유지됩니다.
