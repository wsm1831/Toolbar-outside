# 업무 툴바 (Toolbar-outside)

Windows 11 화면 아래, 작업 표시줄 바로 위에 떠 있는 둥근 독(dock) 모양 툴바입니다.
카테고리 아이콘을 누르면 하위 아이콘들이 위로 튀어오르고, 누르면 홈페이지·프로그램·폴더가 열립니다.
인터넷망(외부망) PC에서 쓰는 것을 전제로 합니다.

## 기능

| 위치 | 기능 |
| --- | --- |
| 홈페이지 | 지정한 사이트 바로가기 (사이트 아이콘 자동 표시) |
| 작업도구 | 메모장, 계산기, 화면 캡처, 그림판, 파일 탐색기, 작업 관리자 등 프로그램 실행 |
| 폴더 | 다운로드, 바탕화면, 문서 등 폴더 열기 |
| 유틸리티 | 빠른 메모, 날짜 계산(D-day·기한·영업일), 타이머·알람, 텍스트 정리, 클립보드 기록, 맞춤법 검사, 번역 |
| 오른쪽 끝 | 시계, 설정, **녹색 불빛(화면 보호기 차단)** |

- 평소에는 반투명(기본 35%)이고, 마우스를 올리면 또렷해집니다.
- 툴바 바깥의 빈 영역은 클릭이 뒤의 창으로 그대로 전달됩니다.
- 항상 다른 창 위에 떠 있습니다. 작업 표시줄 트레이 아이콘으로 숨기기/보이기/종료할 수 있습니다.

### 녹색 불빛 (화면 보호기 차단)
- 초록 = 켜짐(화면 보호기·화면 꺼짐 방지), 회색 = 꺼짐. 한 번 누르면 켜기/끄기.
- Windows 공식 전원 API(Electron `powerSaveBlocker`, `SetThreadExecutionState`)만 사용합니다. 키 입력이나 마우스 움직임을 흉내 내지 않습니다.
- 매일 소등 시간(기본 11:30~13:00)에는 자동으로 꺼집니다. 소등 시간 중에 직접 누르면 그 시간 동안은 켜진 채 유지됩니다. 설정에서 바꿀 수 있습니다.
- 단, 회사 보안 정책(그룹 정책)이 화면 잠금을 강제하는 PC에서는 막히지 않을 수 있습니다.

## 실행 파일 받기

1. GitHub 저장소의 **Actions** 탭 → 가장 최근 "Windows 실행 파일 만들기" 실행을 엽니다.
2. 아래쪽 **Artifacts** 의 `WorkToolbar-portable` 을 내려받아 압축을 풉니다.
3. `WorkToolbar-x.y.z-portable.exe` 를 실행합니다 (설치 없음).

처음 실행할 때 Windows SmartScreen 경고가 나오면 "추가 정보 → 실행"을 누릅니다 (코드 서명이 없는 프로그램이라 나오는 경고).

## 설정

- 툴바의 톱니바퀴 → 설정 창에서 카테고리·항목 추가/삭제/순서 변경, 아이콘 이미지 변경, 투명도, 소등 시간, 자동 실행, 공휴일을 고칠 수 있습니다.
- 설정은 `%APPDATA%\WorkToolbar\config.json` 에 저장됩니다. 형식은 [docs/config-format.md](docs/config-format.md) 참고.
- 빠른 메모는 같은 폴더의 `memo.txt` 에 저장됩니다(암호화되지 않음). 클립보드 기록은 파일로 저장하지 않고 프로그램을 끄면 지워집니다.

## 개발

```bash
npm install
npm start            # 실행 (Windows)
npm run dist         # Windows용 portable exe 만들기 → dist/
```

- `src/main.js` 창·트레이·실행·설정 파일·화면 보호기 차단
- `src/preload.js` 화면에서 쓸 수 있는 기능 목록
- `src/renderer/` 툴바 화면(`app.js`), 유틸리티 패널(`tools.js`)
- `src/settings/` 설정 창
- `scripts/build-icons.js` Lucide 아이콘 묶음 생성, `scripts/preview.js` 브라우저 미리보기 스크린샷
